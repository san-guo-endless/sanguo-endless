# 三国 · 无尽战纪

> 一个纯前端、可离线的三国题材肉鸽卡牌游戏。
> **零依赖、零图片、零网络请求** —— 整个游戏就是一个 HTML 文件。

---

## 🎮 怎么玩

把敌人血条**打空**就过关；打不空，这一局立刻结束。看看你能爬到第几波。

- **伤害 = (攻击力 − 护甲) × 连击数** —— 攻击和连击是两条轴，要一起堆才炸得动
- **武将有词条，位置决定价值**：张飞「前面每张牌 +攻击」越往后越强；许褚「末位时 +攻击」必须放最后
- **顺位就是策略**：同一套牌，换个顺序就是另一种打法
- **三种兵种**：猛将吃攻击 · 骁将吃连击 · 谋士给后面同阵营的牌加伤害%
- **十种流派**：蜀堆末位 / 魏铺前置 / 吴首尾护中间 / 混色 / 空槽 / 破甲 / 连击 / 数量 / 水阵 / 谋士光环

## ✨ 特性

| | |
|---|---|
| 🎯 **纯前端** | 单 HTML 文件，打开就能玩，无需安装 |
| 📴 **完全离线** | 没有一张图片、没有一次网络请求，音效是程序合成的 |
| 📱 **手机适配** | 触屏可玩，出战序列支持「大卡 / 紧凑」两种视图 |
| 🏆 **局外成长** | 战功等级（25 级称号，从乡勇到军神）+ 24 个成就 |
| 🧪 **演武场** | 自选武将 / 军令打木桩，试伤害不写存档 |
| 🎲 **无尽难度** | 敌人血量按 1.18 的指数增长，最终会被「神机营」的每段伤害上限挡住 |

## 🛠 技术说明

- 原生 `HTML + CSS + JavaScript`，**不使用任何框架或第三方库**
- 存档使用 `localStorage`（`sg_save_v1` 局内 / `sg_meta_v1` 局外）
- 单文件版由 `build.ps1` 把 `game.js` / `config.js` / `style.css` 内联生成
